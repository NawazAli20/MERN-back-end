# RESTful web API (MERN back-end) creations

This repo shows how to create RESTful web API (MERN-back end) creations, separated from server.js:
 - server.js //for servering setting and running
 - api/studentRoutes.js //students routes creation
 - connection.js //connection with database

# How to Run 

After cloning the repo, issue:

npm install 

npm run server


From the brower, access: 

http://localhost:3000/api/students/
